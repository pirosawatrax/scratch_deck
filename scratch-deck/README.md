# Scratch Deck

[English](README.en.md)

ターンテーブル風のマウス操作でスクラッチを演奏・録音・編集し、WAVに焼き込む Python 製ソフト。
最終ミックスは REAPER などの DAW で行う想定です。Linux / Windows 対応(ソース配布)、macOS は未テスト。

## インストールと起動

```
pip install -r requirements.txt
python src/main.py                    # 起動
python src/main.py examples/demo.wav  # 音源を指定して起動
```

練習用の音源は `python examples/make_demo_audio.py` で作れます (`examples/demo.wav` は同梱済み)。
MP3 は `soundfile`(libsndfile 1.1 以上)で読み、失敗したら `librosa` に切り替えます。
音源は読込時に 44.1kHz・ステレオへ変換されます。

## 使い方

1. **音源を開く** → 波形が出ます。波形をクリックすると「頭出し位置」(橙の点線)になります。
2. **盤をドラッグ**して演奏。掴んでいる間は盤が手に追従し、止めれば盤も止まり、離すとモーターが等速へ戻します。
   - 「モーター」を入れると盤が回り続けます (切るとブレーキで停止)。
   - 1回転に必要なマウス移動量は「1回転のマウス移動(px)」で変えられます。
3. **● 録音**を押して演奏し、もう一度押すと停止。手の動き `[時間, 速度]` が右下のグラフに出ます。
4. **グラフで編集**: クリックで点を追加、ドラッグで移動、右クリックで削除。曲線は `bezier` / `linear` / `monotone`。
5. **▶ 編集内容を再生**で確認 → **WAV書き出し**。
6. **プリセット**: `presets/` に Baby / Chirp / Transform / Scribble / Crab / Orbit。読み込むと頭出し位置に適用されます。

速度は再生速度の倍率です (1.0=等速、負=逆再生)。位置は `position += velocity` で進み、小数位置は補間して音を取ります。

### ターンテーブル設定 (慣性・モーター・ブレーキ・マット)

| 設定 | 効果 |
| --- | --- |
| 慣性(重さ) | 大きいほど手の動きに遅れて追従 (重い機種) |
| スリップマット摩擦 | 小さいほど手が滑って追従が鈍る |
| モーター立上り | 小さいほど離した後すぐ等速に戻る (高トルク) |
| ブレーキ時間 | モーターOFF時に止まるまでの時間 |
| 33 / 45 rpm | 目標速度 1.0 / 1.35 |
| 手の平滑化 | マウス速度のガタつきを抑える (大きいと反応が鈍い) |

### 補間と音質

- リアルタイム補間: `linear` / `cubic`(既定) / `sinc`。書き出し補間は `sinc`(既定)。
- `sinc` は高速再生時に遮断周波数を下げて折り返しノイズを抑えます。
- 止めた盤が無音になるよう、約3.5Hzのハイパス(DCカット)を通しています。
- 書き出しはクリップ防止のみ行い(ピーク 0.98 まで下げる)、小さい音は持ち上げません。

## REAPER との連携

- 書き出した WAV を REAPER のトラックへドラッグ&ドロップ。
- 「REAPERプロジェクト(.rpp)も作る」にチェックすると、WAV を1トラックに置いた最小のプロジェクトも作ります(実験的機能)。
- GUIなしで一括生成: `python examples/render_cli.py 音源.wav presets/Chirp.json out.wav 1.5 sinc`

## 構成

```
src/
  main.py          GUI本体 (タイマー・各操作)
  audio_engine.py  読込 / 補間 / オフライン描画 / リアルタイム再生
  turntable.py     物理モデル (慣性・モーター・ブレーキ・マット)
  automation.py    点列と補間 / RDP間引き / JSON保存
  recorder.py      手の動きの記録
  waveform.py      波形表示   editor.py  曲線編集   ui_widgets.py  盤のウィジェット
  export.py        WAV書き出し / .rpp 生成
  presets.py       プリセット生成 (python src/presets.py)
tests/test_core.py コアロジックのテスト (python tests/test_core.py)
```

## 動作確認の状況

- コアロジック(補間・描画・物理・オートメーション・録音・書き出し・リアルタイム経路)は自動テスト済み。
- GUI・実際のオーディオデバイス再生・マウスの操作感は、開発環境で実機確認できていません。
  不具合や操作感の調整点は、環境(OS・オーディオ機器)と症状を添えて報告してください。
